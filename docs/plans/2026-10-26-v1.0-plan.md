# 2026-10-26 v1.0 实施计划

更新时间：2026-10-28

## 目标

完成 Rag-AiChat v1.0 可交付版本：文件上传、解析、切分、embedding、pgvector 入库、RAG 问答、引用来源、重新索引、用户管理、管理员管理、系统状态、测试和启动文档。

## 范围

- 后端使用 Spring Boot 3.3.5、Spring Security、MyBatis + MyBatis-Plus、Apache Tika、PostgreSQL/pgvector、Redis。
- 数据库初始化统一使用 `backend/src/main/resources/schema.sql`，不再使用 Flyway。
- RAG 外部能力通过 OpenAI-compatible REST API 配置 embedding 与 LLM。
- 前端继续使用 Vue 3 + Vite + TypeScript + Pinia + Axios。
- 不引入新的构建系统或大型前端框架。

## 实施步骤

1. 增加后端配置、依赖和配置类。
2. 补齐文档文件、文档片段、用户、聊天消息相关实体字段和 Mapper 查询。
3. 实现文件上传、Apache Tika 解析、文本切分、embedding、pgvector 写入和重新索引。
4. 实现 RAG 问答主链路，保存用户问题和 assistant 回答，并返回引用来源。
5. 实现管理员用户管理接口，禁止管理员禁用或降级自己的最后一个有效管理员状态。
6. 实现系统状态接口，展示数据库、Redis、上传目录、embedding 和 LLM 配置状态。
7. 前端补齐管理后台文件、用户、系统状态页面。
8. 前端聊天页接入流式 RAG 问答接口。
9. 更新 README 与 v1.0 规格说明。
10. 运行后端 `mvn clean package` 和前端 `npm run build`。

## 验收

- 管理员可以上传 `.txt`、`.md`、`.pdf`、`.docx` 等 Tika 支持文件。
- 文件列表可查看状态、解析错误和 chunk 数量。
- embedding 或 LLM 未配置时接口返回明确业务错误。
- 用户可以在聊天页选择知识库范围提问并查看回答。
- 管理员可以查看和管理用户。
- 系统状态接口可返回关键组件状态。
- 后端构建和前端构建通过。
